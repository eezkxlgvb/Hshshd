# 🐺 Den — صفحه ورود با انیمیشن هاسکی

یک صفحه ورود زیبا و تعاملی با انیمیشن باز شدن در، راه رفتن و چشم‌های هاسکی.

## ✨ ویژگی‌ها
- انیمیشن در بازشونده هنگام کلیک روی دکمه ورود
- هاسکی با چشم‌های متحرک که پس از ورود موفق خوشحال می‌شود
- طراحی مدرن و پاسخگو (موبایل‌فرندلی)
- دکمه‌های ورود با گوگل و اپل (ظاهری)

## 🚀 اجرا در Railway
1. این ریپازیتوری را به گیت‌هاب آپلود کن.
2. در Railway یک پروژه جدید ایجاد کن و به گیت‌هاب متصل کن.
3. Railway به‌طور خودکار `npm start` را اجرا خواهد کرد.

## 🧑‍💻 اجرا در لوکال
```bash
npm install
npm start
